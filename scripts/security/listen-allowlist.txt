# Listening sockets the gateway may have, read by exposure-target.sh.
# Every socket `ss -tlnH` / `ss -ulnH` reports, loopback included, must match a
# line here, or the exposure check fails.
#
# Columns:
#   gate      a systemd unit that must be active for the line to apply
#             ("-" = always). Feature listeners are gated by their unit, so one
#             file serves base, dev, desktop and prod.
#   proto     tcp | udp
#   address   local address:port as ss prints it, as a bash pattern: escape a
#             literal * [ ] with a backslash. A line without wildcards must be
#             present; a wildcard line may match nothing.
#   firewall  what the live input chain must do with the port:
#               open    admitted from the network (IPv4 rule, no iifname)
#               scoped  never admitted network-wide; an interface-bound
#                       (iifname) rule, or none, is fine
#               closed  not admitted at all
#   domain    optional: the SELinux type every process holding the socket must
#             run in ("-" or absent = not checked; checking needs root for ss -p)
#   images    optional: comma list of images the line applies to (dev, desktop,
#             prod, base, from IMAGE_BASENAME in /etc/buildinfo; "-" or absent = all).
#             On any other image the listener matches nothing and fails.
#
# Adding a line is a security decision: say why in the commit.
